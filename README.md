mend applies AI-written edits in four formats — unified diff, SEARCH/REPLACE blocks, V4A patches, and JSON tool calls — to a tree of text files. It finds the lines each edit names at the first of three matching tiers (exact, trailing-whitespace-insensitive, fully trimmed with re-indentation), and writes every change or none at all. See SPEC.md for the full contract.

## Run it

```sh
node main.ts [options] [PATCH]
```
